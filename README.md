# Vem Viver — aplicativo

Protótipo Android/iOS em React Native + Expo.

## Testar no celular
1. Instale Node.js no computador.
2. Extraia este projeto.
3. Abra o terminal na pasta.
4. Execute `npm install`.
5. Execute `npx expo start`.
6. No Android, instale o Expo Go e leia o QR Code.

## Acesso
O protótipo contém login Google visual. Na produção, a autenticação deve ser conectada ao Google Identity/OAuth e a um backend. A função Membro/Pastoral/Administrador será determinada pelo cadastro no servidor, nunca pelo usuário.
